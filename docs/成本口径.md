## 五、这套数字意味着什么

一个典型任务（2.8 步）大约花 4,711 token、0.047 分（按 GLM-4-FlashX-250414（免费版 Flash 的增强版）），耗时 11.2s（≈4.0s/步）。

按这个量级，**1 元钱能跑约 2,122 个任务**。

所以浏览器操作 Agent 的成本瓶颈**不在模型调用**，而在浏览器进程的内存占用（M6 压测实测：3 并发时 201MB → 481MB）和单步延迟（就是上面那个 s/步）。

> 这是本项目做成本核算最重要的结论：模型便宜到可以忽略，真正的成本是**机器资源和时间**。所以优化方向是并发与步数，不是换更便宜的模型。
