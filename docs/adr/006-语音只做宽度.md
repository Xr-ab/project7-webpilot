# ADR-006 语音只做"宽度"，不进决策链

## 背景

P2 加语音（ASR + TTS）。做完前置实测后拿到这些数字：

| 项 | 实测 |
|---|---|
| ASR 模型体积 | 464MB（faster-whisper small / int8） |
| ASR 模型加载 | **9.93s**（一次性） |
| ASR 转写 | 1.5s / 5.7 秒音频；2.4s / 16.5 秒音频 |
| ASR 准确率 | 短句语义对；长句出现同音错字（**扩展坞 → 扩展物**） |
| TTS 合成 | **1.4~1.7s，且几乎不随文本长度变化**（固定握手开销） |
| TTS 稳定性 | 连续 6 次零失败；同文本三次产出一致 |

同时实测到两个必须正视的问题：

1. whisper 在**非语音音频**上会凭空造句子（合成提示音 → `字幕製作人Zither Harp`）
2. 失败任务的 `note` 是开发者诊断信息（`连续 3 次相同动作：click e1`），念出来是噪音

## 决定

**语音只作为输入/输出的另一种形式，不进入 Agent 的决策链。** 具体四条边界：

| 编号 | 边界 | 落地方式 |
|---|---|---|
| 1 | ASR 结果**只填输入框，绝不自动提交** | `VoiceButton` 只调 `setGoal`，提交仍由用户点按钮 |
| 2 | TTS 失败**降级不阻塞** | 接口返回 `200 + ok:false`，前端只不显示播放按钮，答案照常显示 |
| 3 | **非流式** | 一次性合成 mp3 落盘，前端 `<audio>` 播放；不做边说边播 |
| 4 | 播报文案**独立于界面文案** | `_speech_text()` 只念答案或口语化状态，**不拼 `note`** |

配套的两个实现决定（不是边界，但和边界绑在一起）：

- ASR 模型**单例 + 启动后台预热 + RLock 串行**。不能每次请求加载（+10s），
  不能并发转写（CPU int8 会互相拖慢），也不能 `await` 预热（会卡死 uvicorn 启动）
- 播报**按需生成**（用户点按钮才合成），不随任务完成自动播

## 理由

**为什么语音不进决策链。**
语音不提高任务成功率——它既不改善页面快照，也不改善模型判断。
它改善的是"能不能用"和"能不能演示"。把它塞进决策链（比如让模型"听"页面）
是另一件事，成本高一个数量级，P2 不做。

**为什么绝不自动提交（边界 1）。**
实测已经证明 ASR 会错字，而且错法很危险：`扩展坞 → 扩展物` 是同音字，
模型完全可能据此去搜一个不存在的词。如果语音直接触发提交，
用户看到的是"任务失败了"，而真正的错误发生在他说完话的那 1.5 秒里——
**错误被转移到了一个用户不会怀疑的地方**。让人看一眼再提交，成本 2 秒，
换掉一整类"莫名其妙失败"。

**为什么 TTS 必须降级（边界 2）。**
TTS 依赖微软在线服务，是**我们不可控的第三方**。语音是锦上添花的通道，
它挂了不应该让"看答案"这件主功能跟着挂。这也是第一次在本项目里
把"可选依赖失败"和"主流程失败"分开处理（之前任务失败一律标红）。

**为什么非流式（边界 3）。**
实测 TTS 的 1.5 秒是固定握手开销，不是编码时间。对"任务跑完点一下播放"这个场景，
1.5 秒完全可接受。做流式要为它引入 WebSocket、分块协议、前端缓冲，
收益要等到"实时对话"才体现——提前做就是过度设计。

**为什么按需生成而不是自动播。**
两个原因：浏览器自动播放策略会拦"没有用户手势"的音频（自动播会被静音甚至拒绝）；
以及用户在公共场合不希望突然出声。**语音必须由用户主动触发。**

## 后果

- ✅ 语音任何一环挂掉，纯文本主流程完全不受影响（可以现场演示"关掉语音照常用"）
- ✅ 播报有天然缓存：内容由 meta 决定、meta 终态不变，所以"文件存在就返回"就够，
  实测第二次调用 0.041s（比首次快 47 倍），且不需要任何失效策略
- ⚠️ **做不了实时语音对话**。真要"说完立刻回应"，`synthesize()` 的 save-to-file
  写法要改成 WebSocket 推 chunk，接口形状会变
- ⚠️ 本地部署成本 +464MB 模型、+10s 启动预热。可以 `VOICE_ENABLED=false` 关掉，
  关掉后语音接口返回 503、前端按钮置灰
- ⚠️ TTS 无离线兜底。章程风险 R4 的备选是 CosyVoice 本地部署，
  但目前 edge-tts 实测可用，暂不引入
- ⚠️ ASR 的"幻听"问题在代码层无法根治（whisper 没有"我不确定"这个输出），
  只能靠边界 1 在产品层兜住。**这条不会因为换模型而消失，只会变轻**
